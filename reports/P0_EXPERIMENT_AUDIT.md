# TimelyRAG P0 experiment integrity audit

**Overall WARN · numeric reproduction REPRO_PARTIAL.** All eight full-domain repaired runs have verifiable predictions and evaluation records. All eight plain retriever nDCG@10 cells and both Law automatic cells fall within the protocol's ±0.005 tolerance. The six other automatic cells miss. The verdict covers the two P0 backbones, four TimelyQABench domains, and released retrieval labels. Semantic review is same-family and provisional. The independently executable checks below passed.

### B · Score normalization — WARN

The published implementation conditions ideal DCG and the AP denominator on relevant documents actually retrieved in the top 10. This inflates both metrics relative to the standard all-gold calculation when positives are missing. For a ranking with one hit at rank one and two gold documents at k=2, the author nDCG/AP are 1/1 and the standard values are 0.613147/0.5. The author metrics use relevance membership; there is no post-hoc rescaling of reported metrics by a model's score extrema. Separately, min–max normalization of candidate scores is an input to the author's reranking algorithm. The evaluator preserves the original definition for parity, saves standard nDCG/AP separately and uses full gold for recall. Company BM25 baseline author nDCG is 0.225781 versus standard 0.163641. All seven per-query metrics agree with independently computed values under the stated conventions, absolute tolerance 1e-12. See `vendor/TimelyRAG/metrics.py:5–38`, `vendor/TimelyRAG/retrieval.py:100–109`, `scripts/baseline_isolated.py:169–181`, `reports/review_tools/verify_p0_results.py:50–62,107–144`, `reports/baselines/baseline-company-bm25-20261105T013508Z/summary.json:2–10`.

### E · Scope and portability — WARN

Each of the eight configurations ran once on the full released domain. There were no repeat seeds, new-method experiments, external lockbox results, matched automatic-only latency estimates or human judgments by this team. The denominator is 3,000 per run; repeated backbones reuse the same queries. Candidate recall@100 ranges from 0.1381 (Terms dense) to 0.4159 (University BM25), below the proposed 0.90 feasibility threshold for every run. Table 14's exact Company historical label has 469 records: BM25 baseline/auto 0.181037/0.145930 and dense 0.130799/0.105524, vs published 0.186/0.157 and 0.133/0.130. These are descriptive direction matches for the historical decline; exact automatic values miss. See `reports/baselines/baseline-company-bm25-20261105T013508Z/subgroups_raw.json:107–120` and dense `baseline-company-dense-20261105T013616Z/subgroups_raw.json:107–120`, `reports/baseline_parity.md:5–22`, `docs/guides/ACL2027_Temporal_RAG_Replication_Protocol.md:72–89,144–158`. [Paper Table 14](https://aclanthology.org/2026.findings-emnlp.398.pdf#page=14)

The paper's Eq. 7 describes a sigmoid based on event-time presence/granularity, while released automatic scoring uses availability, variance, gap and other signals, discrete alpha, a separate gate and margin weights. Retrieval's year-to-hour granularity IDs are opposite the gap-normalizer's lookup. All released domains have zero parsed document event times. Each has 22–106 unparseable document insertion timestamps even though the raw field is present. The release makes equal-or-future insertion times undefined for distance, then assigns unknown affinity 0.5; candidates remain eligible. Eq. 3 describes clause intervals and paper causality allows equality. All eight paper Table 15 values labeled nDCG@5 coincide to three decimals with Table 4's corresponding automatic nDCG@10 values. This does not identify the authors' actual cutoff or establish the cause of a mismatch. See `vendor/TimelyRAG/alpha.py:29–60,73–90`, `vendor/TimelyRAG/retrieval.py:145–185`, `vendor/TimelyRAG/time_scores.py:44–74`, `manifests/temporal_metadata_audit.json:2–40`. [Paper §§3.3 and 5.2.1, Tables 4 and 15](https://aclanthology.org/2026.findings-emnlp.398.pdf)

The measured hardware was an RTX 4060 Laptop GPU; dense workers report 3,065,894,912–4,235,892,224 peak Torch-allocated bytes. BM25's zero is assigned in code for the CPU path. Runtime summaries reproduce the measured distributions. Reranking durations include auto, all eleven trials and in-memory ranking/metric capture. The timer ends before prediction serialization/write/flush, despite the report's broad word “logging.” Neither total worker time nor grid time measures isolated automatic latency. The paper used an RTX 6000 Ada and different Table 9 settings. See `scripts/baseline_isolated.py:114–137`, `scripts/report_baseline_runtime.py:14–19`, `reports/baseline_runtime.json:12–20,32–40,72–80`, `configs/environment_linux.json:1–11`. [Paper Table 9 and Appendix C](https://aclanthology.org/2026.findings-emnlp.398.pdf)
