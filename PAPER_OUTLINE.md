# Paper outline (working title: Two Clocks for Temporal Evidence Retrieval)
1. Intro: historical questions differ in which clock they constrain; single-clock rankers return evidence that is inadmissible under the requested semantics. Contributions: (i) two-clock problem formulation with (t, h, intent); (ii) resource from versioned Federal Register rules with verified dates; (iii) routed eligibility + semantic gating baseline; (iv) analysis of single-clock failures.
2. Related work: Q-TIE, Re3, IA-RAG, FRESCO, TimelyRAG, TEMPS; bitemporal DB theory and agent memory stores.
3. Formulation and intents. 4. Data and annotation (provenance, human judgments, agreement). 5. Method (router, eligibility, gate). 6. Experiments: baselines B0-B6 + Q-TIE; family-held-out; cluster CIs; ablations (routing, gate, semantic). 7. Analysis: where each clock fails; timestamp noise; abstention. 8. Limitations: publication != knowledge, one jurisdiction, templated queries.
Status: sections 3, 5, 6 have preliminary numbers; 4 needs human labels; second domain missing. Q-TIE appears only as the labelled Q-TIE-style stand-in (EXPERIMENT_RESULTS.md); state in Limitations that official code was unavailable and the learned intent model was replaced by a date parser.
